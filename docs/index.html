the skeleton every domain is built on, and nothing more than a skeleton

spinedomains labsposters corpus

Many domains. Many laboratories. Many implementations. One common spine. A domain satisfies ten invariants and then authors its own purpose, contract, context, state model, invariants, failure modes, evidence requirements, workflow and artifact model. Those nine are never shared.

the ten invariants

idnamerule
D1one interface headerThe domain declares its capability surface in exactly one normative interface file. The header contains no implementation and names no implementation.
D2registry, not call sitesImplementations are bound by a registry. No caller names an implementation. Deleting the registry must break binding, never compilation of callers.
D3ports include mock and templateThe same interface is realised on N substrates. Two are mandatory: mock (runs with nothing attached) and template (the empty port a third party fills).
D4the harness is the definitionConformance is an executable suite, not prose. Every condition carries a measurable acceptance criterion with units. A condition whose limit is unknown is written 'not established' — an invented limit is worse than an absent one.
D5one verb table, many surfacesskills/verbs.json is the single source for every agent surface. A surface is generated, never hand-written.
D6closed attachment setForeign systems attach at a fixed enumerated set of points or not at all. A new kind of attachment is a contract change, not a patch.
D7roadmap is dataWork is packages/tracks/milestones in JSON, validated in `make check`. Every package declares dependencies; packages with none are startable immediately by anyone.
D8measure, then claimA performance, coverage or completeness claim requires a recorded measurement in the same commit. One package, one pull request, one proof.
D9the engine is common, the workflow is notDomains share this skeleton and NOTHING else. Each domain authors its own purpose, contract, context, state model, invariants, failure modes, evidence requirements, workflow and artifact model. Reuse the smallest primitive. Architecture is never inferred from code reuse.
D10nothing pretendsBuilt, wired-unproven, and not-built are three different states and are reported as three. No stub that looks alive. Absence is reported with where it was looked for.
D11adopt before inventing; vendor without driftingWhere an external standard already covers a need, the spine emits that standard and records what it does NOT cover. Where a sovereign domain must vendor a shared primitive rather than import it, a behavioural drift check proves the copy still answers as the reference does.

adopted, not invented

standardreplaceswhat it does NOT do
OWASP CycloneDX, ECMA-424the ad-hoc BoM CSV invented in core.bomit does not price anything. Provenance of a price stays this estate's problem.
Development Containers Specificationa bespoke 'how to start this lab' README stepit does not provision hardware, and it is not a multi-container orchestrator — compose is still referenced for that.
RO-Cratean evidence folder whose contents only a human could interpretit asserts nothing about whether the measurement is correct.
Technology Readiness Levels, ISO 16290:2013nothing — the five-rung ladder stays. This is a DECLARED MAPPING so a collaborator can state a TRL to a funder without inventing onea rung does not compute a TRL. The mapping gives a RANGE, and the assessment itself is left to the adopting organisation, exactly as ISO 16290 leaves it.
Unified Code for Units of Measurefree-text units in conformance conditions ('Hz and Hz/s', 'microseconds')it carries no ontology; QUDT is where a unit links to its quantity kind.

Checked, not merely printed: tools/anti_conflate.py refuses a text that equates any pair above, and passes a text that distinguishes them.
